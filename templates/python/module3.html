➕ Module 3: Operators

Learn how Python uses operators to perform calculations, compare values, assign values, and create logical expressions.

🎯 Learning Objectives

  • Understand arithmetic operators.
  • Use assignment operators.
  • Compare values.
  • Use logical operators.
  • Understand operator precedence.
  • Use operators in simple Python programs.

📖 1. What Is an Operator?

An operator is a symbol or keyword that tells Python to perform an operation. 

result = 10 + 5
print(result)

The answer is:

15

➗ 2. Arithmetic Operators

Arithmetic operators are used for calculations.

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • // Floor division
  • % Remainder
  • ** Exponentiation
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)

The remainder operator (%)

The percentage symbol gives the remainder after division. 

print(10 % 3)

The answer is:

1

🟰 3. Assignment Operators

Assignment operators are used to store and update values. 

score = 50

score += 10

print(score)

The answer is:

60

Other examples include:

score -= 5
score *= 2
score /= 2

🔍 4. Comparison Operators

Comparison operators compare two values and return either True or False.

  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to
age = 16

print(age == 16)
print(age > 18)
print(age < 18)
print(age != 20)

🧠 5. Logical Operators

and

and requires both conditions to be True. 

age = 20

print(age >= 18 and age <= 30)

or

or is True when at least one condition is True. 

day = "Saturday"

print(day == "Saturday" or day == "Sunday")

not

not reverses a Boolean value. 

is_raining = False

print(not is_raining)

📐 6. Operator Precedence

Python follows an order when several operators appear in the same expression. 

result = 2 + 3 * 4

print(result)

The answer is 14 because multiplication happens before addition.

You can use parentheses to change the order:

result = (2 + 3) * 4

print(result)

This gives 20.

💻 7. Operators With User Input

Operators become more useful when combined with input. 

first = float(input("Enter first number: "))
second = float(input("Enter second number: "))

total = first + second

print("Result:", total)

This program asks the user for two numbers and adds them.

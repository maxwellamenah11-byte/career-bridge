📖 Lesson 1: What Is Programming?

A computer does not automatically know what you want it to do. It needs instructions.

Programming is the process of writing instructions that a computer can follow to perform a task.

Example

Imagine you want a computer to calculate the total cost of two items. You could give it instructions such as:

  1. Store the price of the first item.
  2. Store the price of the second item.
  3. Add the two prices.
  4. Display the result.

A programming language allows us to express those instructions in a form a computer can process.

🐍 Lesson 2: What Is Python?

Python is a high-level, general-purpose programming language. It is designed to have readable syntax and is used for many different types of software projects.

Where is Python used?

  • 🌐 Web development
  • 🤖 Artificial intelligence and machine learning
  • 📊 Data analysis
  • ⚙️ Automation
  • 🧪 Scientific computing
  • 🖥️ Software development
  • 🎮 Some types of game development

Why is Python popular?

Python has relatively simple and readable syntax, which makes it a popular choice for beginners as well as experienced developers.

print("Python is fun!")

💻 Lesson 3: Your First Python Program

One of the simplest things you can do in Python is display information on the screen. 

print("Hello, World!")

Understanding the code

print() is a Python function that displays information.

The text inside quotation marks is called a string.

Try changing the message: 

print("Welcome to Career Bridge!")
print("I am learning Python.")

Python executes these instructions from top to bottom.

✍️ Lesson 4: Comments

Comments are notes written inside code to help humans understand what the program is doing.

Python ignores comments when executing the program. 

# This is a comment

print("Hello!")

A single-line comment begins with the # symbol.

Why use comments?

  • To explain complicated code.
  • To make programs easier to understand.
  • To leave notes for yourself or other programmers.

⌨️ Lesson 5: Getting Input From a User

Programs become more useful when they can receive information from users.

Python provides the input() function for basic keyboard input. 

name = input("What is your name? ")

print("Hello", name)

When this program runs, Python waits for the user to type something and press Enter.

Another example

school = input("What school do you attend? ")

print("Your school is", school)

Notice that we have introduced a variable called name and another called school.

📦 Lesson 6: Introduction to Variables

A variable is a name used to refer to a value stored by a program. 

name = "Maxwell"
age = 16

print(name)
print(age)

In this example, name refers to the text "Maxwell", while age refers to the number 16.

Learn how Python can create, read, write and manage files.

📖 1. What Is File Handling?

File handling means using a program to work with files stored on a computer.

Python can be used to read information from files, create new files, add information to files and modify existing files.

This is useful when a program needs to save information permanently instead of keeping it only in memory.

📂 2. Opening a File

Python uses the open() function to open a file. 

file = open("example.txt", "r")

Here, example.txt is the file name and "r" means read mode.

When working with files, it is generally better to use with open(), which automatically handles closing the file.

📖 3. Reading a File

The read() method reads the contents of a file. 

with open("example.txt", "r") as file:
content = file.read()

print(content)

The contents of the file are stored in the content variable.

📄 4. Reading One Line

The readline() method reads one line from a file. 

with open("example.txt", "r") as file:
line = file.readline()

print(line)

📚 5. Reading All Lines

The readlines() method reads the lines and returns them as a list. 

with open("example.txt", "r") as file:
lines = file.readlines()

print(lines)

You can also loop through the file directly. 

with open("example.txt", "r") as file:

for line in file:
    print(line.strip())

✍️ 6. Writing to a File

The "w" mode allows you to write to a file. 

with open("notes.txt", "w") as file:
file.write("Welcome to Python!")

If the file does not exist, Python can create it.

Be careful with "w": writing to an existing file can replace its previous contents.

➕ 7. Adding to an Existing File

The "a" mode means append. It adds new content to the end of an existing file. 

with open("notes.txt", "a") as file:
file.write("\nLearning Python is fun!")

The existing contents remain, and the new text is added after them.

⚙️ 8. File Modes

  • r — Read an existing file.
  • w — Write to a file.
  • a — Append to a file.
  • x — Create a new file.

Understanding file modes helps you choose the correct operation for your program.

🔒 9. Why Use with open()?

Using with open() is recommended because Python automatically closes the file when the block finishes. 

with open("example.txt", "r") as file:
content = file.read()

print(content)

This makes your code cleaner and reduces the chance of leaving files open unnecessarily.

⚠️ 10. Handling File Errors

A program may try to open a file that doesn't exist. You can handle this using try and except. 

try:

with open("missing.txt", "r") as file:
    content = file.read()

print(content)

except FileNotFoundError:

print("The file was not found.")

This prevents the program from stopping unexpectedly when the file cannot be found.

📝 11. Writing Multiple Lines

You can write multiple lines to a file. 

with open("students.txt", "w") as file:

file.write("Alex\n")
file.write("David\n")
file.write("Sarah\n")

The \n creates a new line.

🔄 12. Combining File Handling With Lists

Files can work together with lists and loops. 

students = ["Alex", "David", "Sarah"]

with open("students.txt", "w") as file:

for student in students:
    file.write(student + "\n")

This program saves every name from the list into a file.

💻 13. Mini Project: Student Notes

Let's create a simple program that allows a user to enter a note and save it to a file. 

note = input("Enter your note: ")

with open("notes.txt", "a") as file:
file.write(note + "\n")

print("Your note has been saved.")

Every time the program runs, the new note is added to the file.

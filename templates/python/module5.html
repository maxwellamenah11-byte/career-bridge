🔁 Module 5: Loops

Learn how to repeat instructions efficiently using Python's for and while loops.

🎯 Learning Objectives

  • Understand why loops are useful.
  • Use for loops.
  • Use the range() function.
  • Use while loops.
  • Understand infinite loops.
  • Use break and continue.
  • Build practical programs using loops.

📖 1. What Is a Loop?

A loop allows a program to repeat a section of code. This is useful when you need to perform the same action multiple times.

Without a loop:

print("Hello")

print("Hello")
print("Hello")
print("Hello")
print("Hello")

A loop lets us accomplish the same task more efficiently.

🔄 2. The for Loop

A for loop is commonly used when you want to repeat something for each item in a sequence. 

for number in [1, 2, 3, 4, 5]:
print(number)

The program prints:

1

2
3
4
5

🔢 3. The range() Function

The range() function is commonly used with for loops to generate a sequence of numbers. 

for number in range(5):
print(number)

This prints:

0

1
2
3
4

Notice that range(5) starts at 0 and stops before 5.

Starting from another number

for number in range(1, 6):
print(number)

This prints numbers from 1 through 5.

➕ 4. Using a Step

You can provide a third value to range() to control the step. 

for number in range(0, 11, 2):
print(number)

This prints:

0

2
4
6
8
10

The loop increases by 2 each time.

🔤 5. Looping Through Strings

A for loop can also go through the individual characters in a string. 

name = "Python"

for letter in name:
print(letter)

Each character is printed on a separate line.

📋 6. Looping Through Lists

You can loop through a list and work with each item. 

courses = ["Python", "CV", "LinkedIn"]

for course in courses:
print(course)

This is useful when a program needs to process many items.

⏳ 7. The while Loop

A while loop repeats code while a condition remains true. 

number = 1

while number <= 5:
print(number)
number += 1

The variable changes each time the loop runs, eventually making the condition false.

⚠️ 8. Infinite Loops

Be careful when using while loops. If the condition never becomes false, the loop can continue indefinitely.

For example, avoid creating a loop where the condition never changes:

number = 1

while number <= 5:
print(number)

In this example, number never changes, so the condition remains true.

🛑 9. The break Statement

break immediately stops a loop. 

for number in range(1, 11):

if number == 6:
    break

print(number)

The loop stops when the number reaches 6.

⏭️ 10. The continue Statement

continue skips the current iteration and moves to the next one. 

for number in range(1, 6):

if number == 3:
    continue

print(number)

The number 3 is skipped.

🔁 11. Nested Loops

A loop can be placed inside another loop. This is called a nested loop. 

for row in range(3):

for column in range(3):
    print(row, column)

Nested loops are useful for working with grids, tables and other repeated structures.

💻 12. Practical Example

Let's create a simple multiplication table. 

number = int(input("Enter a number: "))

for i in range(1, 11):
print(number, "x", i, "=", number * i)

If the user enters 5, the program produces the multiplication table for 5.

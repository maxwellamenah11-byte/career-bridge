Learn how to create reusable blocks of Python code using functions.

🎯 Learning Objectives

  • Understand what functions are.

  • Call functions.
  • Use parameters and arguments.

  • Return values from functions.
  • Understand local and global variables.
  • Build practical programs using functions.

📖 1. What Is a Function?

A function is a reusable block of code designed to perform a particular task.

Functions help programmers avoid repeating the same code many times. 

def greet():
print("Hello!")

greet()

The keyword def is used to create a function. The function is then called using its name followed by parentheses.

🔨 2. Creating a Function

A basic Python function follows this structure: 

def function_name():
# code goes here

For example:

def welcome():
print("Welcome to Career Bridge!")

welcome()

The code inside the function only runs when the function is called.

📞 3. Calling a Function

Creating a function does not automatically execute it. You need to call it. 

def say_hello():
print("Hello!")

say_hello()

You can call the same function multiple times. 

def say_hello():
print("Hello!")

say_hello()
say_hello()
say_hello()

📦 4. Parameters and Arguments

A parameter allows a function to receive information. 

def greet(name):
print("Hello", name)

greet("Alex")

Here, name is the parameter and "Alex" is the argument.

Another example

def square(number):
print(number * number)

square(5)

👥 5. Multiple Parameters

A function can accept more than one parameter. 

def add_numbers(a, b):
print(a + b)

add_numbers(10, 5)

The first argument is assigned to a and the second argument is assigned to b.

⚙️ 6. Default Parameters

You can give a parameter a default value. 

def greet(name="Student"):
print("Hello", name)

greet()
greet("David")

If no argument is provided, Python uses the default value.

↩️ 7. Returning Values

A function can send a result back to the part of the program that called it using return. 

def add(a, b):
return a + b

result = add(10, 5)

print(result)

The returned value can be stored in a variable and used elsewhere in the program.

➗ 8. Practical Calculator Function

Functions can be used to organize a calculator program. 

def add(a, b):
return a + b

def subtract(a, b):
return a - b

def multiply(a, b):
return a * b

def divide(a, b):
return a / b

print(add(10, 5))
print(subtract(10, 5))
print(multiply(10, 5))
print(divide(10, 5))

🌍 9. Local and Global Variables

A variable created inside a function is normally local to that function. 

def show_name():
name = "Alex"
print(name)

show_name()

A variable created outside a function can be accessed from different parts of the program. 

school = "Career Bridge"

def show_school():
print(school)

show_school()

⌨️ 10. Functions With User Input

Functions can work together with user input. 

def greet_user(name):
print("Welcome", name)

name = input("Enter your name: ")

greet_user(name)

💻 11. Mini Project: Student Average

Let's create a function that calculates the average of three scores. 

def calculate_average(math, english, physics):
total = math + english + physics
average = total / 3
return average

math = float(input("Enter Mathematics score: "))
english = float(input("Enter English score: "))
physics = float(input("Enter Physics score: "))

average = calculate_average(math, english, physics)

print("Average:", average)

This program separates the calculation into its own reusable function.

📖 1. What Is a Function?

A function is a reusable block of code designed to perform a particular task.

Functions help you avoid repeating the same code many times. 

def greet():
print("Hello, welcome to Python!")

greet()

The def keyword is used to define a function. The function is then called using its name followed by parentheses.

📥 2. Parameters and Arguments

A function can receive information through parameters. 

def greet(name):
print("Hello", name)

greet("Alex")

Here, name is the parameter and "Alex" is the argument passed to the function.

➕ 3. Multiple Parameters

A function can have more than one parameter. 

def add_numbers(a, b):
print(a + b)

add_numbers(10, 5)

The values are matched with the parameters in the order they are supplied.

↩️ 4. Returning Values

Instead of printing a result, a function can return a value using return. 

def add_numbers(a, b):
return a + b

result = add_numbers(10, 5)

print(result)

The returned value can then be stored in a variable or used in another calculation.

⚙️ 5. Default Parameters

You can give a parameter a default value. 

def greet(name="Student"):
print("Hello", name)

greet()
greet("Alex")

If no argument is supplied, Python uses the default value.

🌍 6. Variable Scope

A variable created inside a function is normally local to that function. 

def show_message():
message = "Hello Python"
print(message)

show_message()

The message variable belongs to the function's local scope.

Variables created outside functions can have a wider scope. Understanding scope helps prevent unexpected changes to data in larger programs.

🔁 7. Functions With Loops

Functions can contain loops and other Python statements. 

def print_numbers():
for number in range(1, 6):
    print(number)

print_numbers()

🧠 8. Functions With Lists

Functions can also receive lists as arguments. 

def show_students(students):

for student in students:
    print(student)

names = ["Alex", "David", "Sarah"]

show_students(names)

📦 9. What Is a Module?

A module is a Python file containing code that can be reused in another Python program.

Python comes with many built-in modules.

For example, the math module provides useful mathematical functions. 

import math

print(math.sqrt(25))

The answer is 5.0.

📐 10. Using the Math Module

import math

print(math.pi)
print(math.sqrt(64))
print(math.ceil(4.2))
print(math.floor(4.8))

Modules allow programmers to use code that has already been written instead of creating everything from scratch.

🎲 11. The Random Module

Python's random module can generate random values. 

import random

number = random.randint(1, 10)

print(number)

This generates a random whole number between 1 and 10.

🛠️ 12. Creating Your Own Module

You can create your own module by putting Python functions inside another .py file.

For example, create a file called calculator.py. 

def add(a, b):
return a + b

def subtract(a, b):
return a - b

Another Python file can import it. 

import calculator

print(calculator.add(10, 5))
print(calculator.subtract(10, 5))

🏗️ 13. Why Functions Matter

  • They reduce repeated code.
  • They make programs easier to understand.
  • They make debugging easier.
  • They allow code to be reused.
  • They make large programs easier to organize.

Professional Python programs often contain many functions working together.

💻 14. Final Mini Project: Student Grade Calculator

Let's combine functions, lists, loops and calculations. 

def calculate_average(scores):

total = 0

for score in scores:
    total += score

return total / len(scores)

def get_grade(average):

if average >= 70:
    return "A"

elif average >= 60:
    return "B"

elif average >= 50:
    return "C"

elif average >= 45:
    return "D"

elif average >= 40:
    return "E"

else:
    return "F"

scores = [75, 68, 82, 70, 90]

average = calculate_average(scores)
grade = get_grade(average)

print("Scores:", scores)
print("Average:", average)
print("Grade:", grade)

This project demonstrates how multiple functions can work together to solve a real problem.

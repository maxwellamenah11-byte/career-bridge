🗂️ Module 8: Dictionaries & Sets

Learn how to organize data using Python dictionaries and sets.

🎯 Learning Objectives

  • Understand dictionaries and key-value pairs.
  • Create and access dictionary data.
  • Add, update and remove dictionary items.
  • Loop through dictionaries.
  • Use useful dictionary methods.
  • Understand sets.
  • Add and remove items from sets.
  • Understand set operations.
  • Build a practical program using dictionaries and sets.

📖 1. What Is a Dictionary?

A dictionary stores information as key-value pairs. Instead of accessing information using numerical indexes, you use a key. 

student = {
"name": "Alex",
"age": 16,
"course": "Python"

}

print(student)

In this example, name, age and course are keys.

🔑 2. Accessing Dictionary Values

You can access a value using its key. 

student = {
"name": "Alex",
"age": 16,
"course": "Python"

}

print(student["name"])
print(student["course"])

You can also use get(). 

print(student.get("age"))

Using get() can be useful when a key might not exist.

➕ 3. Adding Dictionary Items

You can add a new key-value pair by assigning a value to a new key. 

student = {
"name": "Alex",
"age": 16

}

student["course"] = "Python"

print(student)

✏️ 4. Updating Dictionary Items

Assigning a new value to an existing key changes that value. 

student = {
"name": "Alex",
"age": 16

}

student["age"] = 17

print(student)

🗑️ 5. Removing Dictionary Items

Using pop()

student = {
"name": "Alex",
"age": 16,
"course": "Python"

}

student.pop("age")

print(student)

Using del

del student["course"]

print(student)

🔄 6. Looping Through a Dictionary

You can loop through dictionary keys. 

student = {
"name": "Alex",
"age": 16,
"course": "Python"

}

for key in student:
print(key)

You can also access both keys and values using items(). 

for key, value in student.items():
print(key, ":", value)

📋 7. Useful Dictionary Methods

keys() returns the dictionary keys.

print(student.keys())

values() returns the dictionary values.

print(student.values())

items() returns key-value pairs.

print(student.items())

📏 8. Dictionary Length

You can use len() to find the number of key-value pairs. 

student = {
"name": "Alex",
"age": 16,
"course": "Python"

}

print(len(student))

🧩 9. Nested Dictionaries

A dictionary can contain another dictionary. 

students = {
"student1": {
    "name": "Alex",
    "score": 85
},

"student2": {
    "name": "David",
    "score": 90
}

}

print(students["student1"]["name"])
print(students["student2"]["score"])

Nested dictionaries are useful for organizing more complex information.

🔵 10. What Is a Set?

A set is a collection of unique items. Sets are written using curly brackets. 

numbers = {1, 2, 3, 4, 5}

print(numbers)

Sets automatically remove duplicate values. 

numbers = {1, 2, 2, 3, 3, 4}

print(numbers)

➕ 11. Adding Items to a Set

Use add() to add an item. 

skills = {"Python", "HTML"}

skills.add("CSS")

print(skills)

🗑️ 12. Removing Set Items

You can use remove() to remove an item. 

skills = {"Python", "HTML", "CSS"}

skills.remove("HTML")

print(skills)

You can also use discard(). Unlike remove(), discard() does not raise an error if the item isn't present. 

skills.discard("JavaScript")

🔗 13. Set Operations

Union

Union combines items from two sets. 

a = {1, 2, 3}

b = {3, 4, 5}

print(a | b)

Intersection

Intersection returns items that exist in both sets. 

print(a & b)

In this example, the common item is 3.

⚖️ 14. Dictionary vs Set

  • Dictionary: stores key-value pairs.
  • Set: stores unique values.
  • Dictionaries use keys to access values.
  • Sets are useful when duplicate values should be removed. 
student = {
"name": "Alex",
"age": 16

}

skills = {"Python", "HTML", "CSS"}

💻 15. Mini Project: Student Profile

Let's combine dictionaries, lists and loops to create a simple student profile. 

student = {
"name": "Alex",
"age": 16,
"skills": ["Python", "HTML", "CSS"]

}

print("Name:", student["name"])
print("Age:", student["age"])

print("Skills:")

for skill in student["skills"]:
print("-", skill)

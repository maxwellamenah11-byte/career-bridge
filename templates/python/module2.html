📖 Lesson 1: What Is a Variable?

A variable is a name that refers to a value in a program. Variables allow us to store information and use it later. 

name = "Alex"
age = 16

Here, name refers to the text "Alex", while age refers to the number 16.

Changing a variable

A variable can be assigned a new value. 

age = 16
age = 17

print(age)

The output will be: 

17

✏️ Lesson 2: Naming Variables

Python has rules and conventions for naming variables.

Good examples

first_name = "Alex"
student_age = 16
total_score = 85

Important rules

  • A variable name can contain letters, numbers and underscores.
  • A variable name cannot start with a number.
  • Spaces are not allowed in variable names.
  • Python variable names are case-sensitive.
  • Do not use Python keywords as variable names.

Example

name = "Alex"
Name = "David"

print(name)
print(Name)

name and Name are different variables because Python is case-sensitive.

🔤 Lesson 3: Strings

A string is a sequence of characters, usually used to represent text. 

name = "Maxwell"
school = "Career Bridge"
message = "Welcome!"

Strings can be written using single or double quotation marks. 

name = "Alex"

city = 'Warri'

Combining strings

You can combine strings using the + operator. 

first_name = "Alex"
last_name = "John"

full_name = first_name + " " + last_name

print(full_name)

Output:

Alex John

🔢 Lesson 4: Integers

An integer is a whole number without a decimal part. 

age = 16
score = 85
year = 2026

Integers can be positive, negative or zero. 

temperature = -5
balance = 0
population = 100000

🔢 Lesson 5: Floating-Point Numbers

A floating-point number, commonly called a float, represents a number containing a decimal part. 

price = 1500.50
height = 1.75
temperature = 36.5

Integers and floats can be used in mathematical calculations. 

price = 1500.50
quantity = 2

total = price * quantity

print(total)

✅ Lesson 6: Boolean Values

A Boolean represents one of two values: True or False. 

is_student = True
is_logged_in = False

Booleans are especially useful when programs need to make decisions. We will use them more in Module 4 — Conditional Statements.

🔍 Lesson 7: Checking Data Types

Python provides the type() function to identify the type of a value. 

name = "Alex"
age = 16
height = 1.75
is_student = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))

The results will identify the values as str, int, float and bool.

🔄 Lesson 8: Type Conversion

Sometimes you need to convert a value from one data type to another.

String to integer

age = "16"

age = int(age)

print(age)

String to float

price = "1500.50"

price = float(price)

print(price)

Number to string

age = 16

age_text = str(age)

print(age_text)

⌨️ Lesson 9: Input and Numbers

Remember that input() normally gives you the user's response as a string.

Therefore, if you want to perform mathematical calculations with a number entered by the user, you usually need to convert it. 

age = input("Enter your age: ")

age = int(age)

print(age + 1)

You can also convert the input immediately: 

age = int(input("Enter your age: "))

print(age + 1)

This is a very common pattern in Python programs.

📋 Module 7: Lists & Tuples

Learn how Python stores multiple pieces of data using lists and tuples.

🎯 Learning Objectives

  • Understand what lists are.
  • Create and access list items.
  • Change, add and remove list items.
  • Use list methods.
  • Loop through lists.
  • Understand tuples.
  • Know the difference between lists and tuples.
  • Build a practical program using lists.

📖 1. What Is a List?

A list is a collection that allows you to store multiple values in a single variable. 

fruits = ["apple", "banana", "orange"]

print(fruits)

Lists are written using square brackets [ ].

A list can contain strings, numbers, or even different types of data. 

student = ["Alex", 16, 85.5, True]

print(student)

🔢 2. Accessing List Items

Python uses indexes to access items in a list. Indexing starts from 0. 

fruits = ["apple", "banana", "orange"]

print(fruits[0])
print(fruits[1])
print(fruits[2])

The first item is at index 0, the second is at index 1, and so on.

🔙 3. Negative Indexing

Python also allows negative indexes. 

fruits = ["apple", "banana", "orange"]

print(fruits[-1])
print(fruits[-2])

-1 refers to the last item, while -2 refers to the second-to-last item.

✏️ 4. Changing List Items

Lists are changeable. You can replace an item using its index. 

fruits = ["apple", "banana", "orange"]

fruits[1] = "mango"

print(fruits)

➕ 5. Adding Items

Using append()

append() adds an item to the end of a list. 

fruits = ["apple", "banana"]

fruits.append("orange")

print(fruits)

Using insert()

insert() adds an item at a specific position. 

fruits = ["apple", "orange"]

fruits.insert(1, "banana")

print(fruits)

➖ 6. Removing Items

remove()

fruits = ["apple", "banana", "orange"]

fruits.remove("banana")

print(fruits)

pop()

pop() removes an item using its index. 

fruits = ["apple", "banana", "orange"]

fruits.pop(1)

print(fruits)

Calling pop() without an index removes the last item.

📏 7. Finding the Length of a List

The len() function tells you how many items are inside a list. 

fruits = ["apple", "banana", "orange"]

print(len(fruits))

🔍 8. Checking if an Item Exists

You can use in to check whether an item is inside a list. 

fruits = ["apple", "banana", "orange"]

if "banana" in fruits:
print("Banana is available.")

🔄 9. Looping Through a List

A for loop can be used to go through every item in a list. 

fruits = ["apple", "banana", "orange"]

for fruit in fruits:
print(fruit)

🔢 10. Sorting Lists

The sort() method can arrange items in order. 

numbers = [5, 2, 8, 1, 3]

numbers.sort()

print(numbers)

You can also sort numbers in descending order. 

numbers = [5, 2, 8, 1, 3]

numbers.sort(reverse=True)

print(numbers)

📦 11. Tuples

A tuple is another way to store multiple values. Tuples use parentheses ( ). 

colors = ("red", "green", "blue")

print(colors)

Unlike lists, tuples cannot normally be changed after they are created. 

coordinates = (10, 20)

print(coordinates[0])
print(coordinates[1])

⚖️ 12. Lists vs Tuples

  • List: uses [ ] and can be changed.
  • Tuple: uses ( ) and cannot normally be changed. 
my_list = ["Python", "Java", "C++"]

my_tuple = ("Python", "Java", "C++")

Use a list when your collection needs to change. Use a tuple when the values should remain fixed.

💻 13. Mini Project: Student Score Manager

Let's create a simple program that stores student scores and calculates the average. 

scores = [80, 75, 90, 85, 70]

total = 0

for score in scores:
total += score

average = total / len(scores)

print("Scores:", scores)
print("Average:", average)

This demonstrates how lists, loops, variables and len() can work together.

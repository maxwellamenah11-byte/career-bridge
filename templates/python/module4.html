🧠 Module 4: Conditional Statements

Learn how to make Python programs make decisions using if, elif, and else.

🎯 Learning Objectives

  • Understand conditional statements.
  • Use if statements.
  • Use else statements.
  • Use elif for multiple conditions.
  • Combine conditions with logical operators.
  • Build simple decision-making programs.

📖 1. What Are Conditional Statements?

A conditional statement allows a program to make a decision based on whether a condition is true or false.

For example, a program can check whether someone is old enough to vote.

age = 20

if age >= 18:
    print("You can vote.")

Because the condition is true, Python runs the code inside the if block.

🔹 2. The if Statement

The if statement runs a block of code only when its condition is true. 

temperature = 30

if temperature > 25:
    print("It is hot.")

Important: Indentation

Python uses indentation to determine which statements belong to an if block. 

age = 18

if age >= 18:
    print("Adult")

The spaces before print() are important.

🔹 3. The else Statement

else runs when the if condition is false. 

age = 15

if age >= 18:
    print("You are an adult.")
else:
    print("You are under 18.")

💻 What Is a Computer?

A computer is an electronic device that receives data, processes it, stores information, and produces useful results.

⚙️ Hardware

Hardware refers to the physical parts of a computer that you can see and touch.

  • Monitor
  • Keyboard
  • Mouse
  • System unit
  • Printer
  • Speakers

🧩 Software

Software refers to the programs and instructions that tell a computer what to do.

  • Operating systems
  • Web browsers
  • Word processors
  • Spreadsheet applications
  • Presentation software

⌨️ Input Devices

Input devices allow users to send information or commands to a computer.

  • Keyboard
  • Mouse
  • Microphone
  • Scanner
  • Webcam

🖨️ Output Devices

Output devices present information from a computer to the user.

  • Monitor
  • Printer
  • Speakers
  • Headphones
💡 Key Point: Hardware is the physical part of a computer, while software consists of the programs and instructions that make the computer perform tasks.

📝 Module Summary

Computers use hardware and software to process information and perform tasks. Understanding these basic components makes it easier to use technology effectively.

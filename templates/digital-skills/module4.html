📝 Microsoft Word & Document Creation

Word-processing skills are useful in school, university, business, and the workplace. Microsoft Word is one of the most commonly used applications for creating and formatting documents.

🎯 What You Will Learn

  • What a word processor is
  • How to create and save documents
  • How to format text
  • How to use headings and lists
  • How to create professional documents

💻 What Is a Word Processor?

A word processor is software used to create, edit, format, save, and print text-based documents.

Examples include Microsoft Word, Google Docs, and LibreOffice Writer.

📄 Creating a Document

When creating a document, you can enter text using the keyboard and then edit the content as needed.

A document should normally be saved regularly so that your work is not lost.

✏️ Formatting Text

Formatting changes the appearance of text and can make a document easier to read.

  • Bold — makes text stand out.
  • Italic — gives text a slanted appearance.
  • Underline — places a line below text.
  • Font size — controls how large text appears.
  • Font type — changes the style of the letters.
  • Text alignment — controls where text appears on the page.

📑 Headings

Headings help organize a document into clear sections. They make longer documents easier to read and navigate.

🔢 Lists

Lists can be used to organize information clearly.

  • Bulleted lists are useful for unordered information.
  • Numbered lists are useful when the order matters.

💾 Saving Documents

Saving a document stores your work so that it can be opened and edited later.

It is a good habit to give files clear names so that they are easy to find.

👔 Creating Professional Documents

Professional documents should be clear, organized, readable, and free from unnecessary mistakes.

  • Use clear headings.
  • Keep formatting consistent.
  • Use readable fonts and appropriate sizes.
  • Check spelling and grammar.
  • Review the document before submitting it.
💡 Key Point: Good document formatting is not just about making text look attractive. It helps readers understand information quickly and makes your work look organized and professional.

📝 Module Summary

Word processors allow you to create, edit, format, save, and manage documents. Learning these skills can help you produce better school assignments, CVs, reports, letters, and workplace documents.

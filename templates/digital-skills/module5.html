📊 Microsoft Excel Basics

Microsoft Excel is a spreadsheet application used to organize, calculate, analyze, and present information. Excel is useful in education, business, engineering, finance, and many other careers.

🎯 What You Will Learn

  • What a spreadsheet is
  • How rows, columns, and cells work
  • How to enter and edit data
  • How to use basic formulas
  • How to organize information in a worksheet

📋 What Is a Spreadsheet?

A spreadsheet is a digital document that organizes information into rows and columns. It can also perform calculations automatically.

Microsoft Excel is one of the most widely used spreadsheet applications.

🔲 Cells

A cell is a box where you enter information. Every cell has a unique address based on its column letter and row number.

A1 = Column A, Row 1
B3 = Column B, Row 3
C5 = Column C, Row 5

↔️ Rows and Columns

Rows run horizontally across a worksheet and are identified by numbers.

Columns run vertically and are identified by letters.

✍️ Entering Data

You can enter different types of information into Excel, including text, numbers, and dates.

  • Names
  • Numbers
  • Prices
  • Dates
  • Scores
  • Descriptions

➕ Basic Formulas

Excel formulas allow you to perform calculations. A formula normally begins with an equals sign (=).

=2+2
=10-5
=4*3
=20/4

Excel can also perform calculations using cell references.

=A1+B1

🧮 Common Functions

Excel includes functions that make calculations easier.

  • SUM — adds numbers together.
  • AVERAGE — calculates the average.
  • MAX — finds the largest value.
  • MIN — finds the smallest value.
=SUM(A1:A5)
=AVERAGE(B1:B5)

📑 Organizing Data

Excel can help you organize large amounts of information. You can use headings, tables, sorting, and filtering to make data easier to understand.

💼 Excel in the Workplace

Excel is useful for many workplace tasks, including budgets, reports, records, calculations, schedules, and data analysis.

💡 Key Point: A cell is identified by its column letter and row number, such as A1. Excel formulas normally begin with an equals sign.

📝 Module Summary

Excel helps users organize information and perform calculations. Understanding cells, rows, columns, formulas, and basic functions provides a strong foundation for more advanced spreadsheet work.

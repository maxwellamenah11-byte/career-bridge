📖 Lesson 1 — Introduction to Python

What is Python?

Python is a programming language used to give instructions to computers.

It is used in areas such as web development, automation, data analysis, artificial intelligence and software development.

Why learn Python?

  • It is beginner-friendly.
  • It is widely used in technology.
  • It can be used to build useful projects.
  • It teaches important programming concepts.

💻 Your first Python program

print("Hello, World!")

The print() function tells Python to display something on the screen.

🧠 Key points

  • Python is a programming language.
  • Python can be used to create many types of programs.
  • print() displays information.
